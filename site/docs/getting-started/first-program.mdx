---
title: First Program
---

Install Affon on macOS arm64 or Linux x64, then download the
[complete demo](https://github.com/neucine/affon/blob/main/examples/first-program.ts)
and run:

```sh
affon first-program.ts
```

It runs on CPU using three in-memory values and no downloaded models. The
Program declares `f32[3]` inputs, exposes its semantic graph through
`inspect()`, and trains one parameter using an explicit SGD transform. The
output shows the input contract, optimizer transition, loss before and after
training, and predictions close to `[2, 4, 6]`.

A Program inspection describes meaning and dependencies. To measure execution
or check a GPU backend, use the [backend support guide](/docs/core/backend-support/)
with your exact shape and dtype.
