---
title: Installation
---

The recommended install path is the hosted installer script.

## Install

```bash
curl -fsSL https://affon.ai/install.sh | bash
```

This installs `affon` into `~/.affon/bin` and updates your shell `PATH`.

On Windows x64, use PowerShell:

```powershell
irm https://downloads.affon.ai/install.ps1 | iex
```

Restart the terminal after installation so the updated user `PATH` is loaded.

## Verify

Check that the binary is available:

```bash
affon --version
```

Run a local script:

```bash
affon examples/hello.ts
```

## Build From Source

If you have access to a source checkout for development:

```bash
cd affon
zig build
./zig-out/bin/affon --version
```
