## Fused index-check experiment, rejected

An experimental `compute_indexing_read` variant checked bounds inside the indexed-read GPU dispatch, wrote a shared error flag, then synchronized before returning to preserve immediate `InvalidCommand`. The source and binary were saved before editing. Nine matched gather, index_select, and embedding cases passed numerical, operator, and Program parity both before and after; `regression-metal-indexing-fused-2026-11-03/` reports zero correctness regressions. The fused source was reverted to the exact pre-experiment file and the original traced binary restored. Do not promote the experimental cell reports or count their isolated-call gains toward the goal.

## Deferred GPU index validation, promoted

The selected `indexing_read` GPU kernel now checks each selected index, atomically records an error flag, and zeroes invalid output elements so later GPU consumers read defined data. The Metal device retains the flag through command submission and checks it at the existing synchronous `Executable.run` completion boundary. Thus an invalid gather, index_select, or embedding call still throws `InvalidCommand` before returning, including when its indices were produced by a preceding GPU operation. Internal preflight waits preserve pending indexed-read flags for that final boundary. No CPU execution shortcut or benchmark-specific selection was introduced.
