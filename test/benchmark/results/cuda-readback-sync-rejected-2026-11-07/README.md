# Rejected CUDA readback synchronization probe

The isolated candidate removed an explicit stream synchronization before the blocking CUDA device-to-host copy. A 19-cell matmul probe passed correctness, with median candidate/baseline ratios of 0.993 operator and 0.991 Program. A 49-cell sample across 25 operation families also passed correctness, but its median ratios were 0.996 operator and 0.998 Program, with 17 operator and 18 Program cells slower. The small and inconsistent gain did not support promotion. The source change was reverted in the isolated checkout, and the current ledger was not changed for this candidate. The retained baseline, candidate, and regression directories contain the raw measurements. A separate JavaScript conversion of `to_bytes()` into nested arrays was slower than native `to_array()` in all tested output sizes.
